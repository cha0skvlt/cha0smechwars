## 1. Копье игрока (Player Lance) ✅

- Игрок управляет отрядом из 3 мехов - Копье (Lance).
- Состав - любое сочетание классов `battle` / `heavy` / `scout`. Дубли разрешены (3x heavy - валидно).
- Игрок напрямую управляет одним мехом (острие), два других - AI-ведомые в режиме FOLLOW.
- **Свитч управления**: клавиша **C** переключает управление на следующего живого меха копья (циклически: C - 1-2-3-1...). Покинутый мех мгновенно переходит под AI-FOLLOW. При смерти управляемого меха - управление автоматически переходит следующему живому.
- **Левелинг ведомых**: каждый мех копья копит свой CE и уровень отдельно (своя строка опыта в UI). Мехи под AI выбирают перки уровня автоматически - той же логикой, что мехи бота. Игрок может качать каждого вдумчиво: переключился по C, выбрал перк вручную, переключился дальше. Автолевелинг - дефолт, ручной выбор - опция для тех, кто пианинит по клаве.
- Ведомые используют существующую физику мехов из `Player.js` / общую DU-физику: то же оружие из `WEAPONS`, тот же `SHIELD.regenRate`, те же i-frames (20/30).

## 2. Меню выбора состава ✅

Переделать текущее меню выбора одного меха:

- Карточки трех классов мехов (battle / heavy / scout) с характеристиками (HP / Shield / Speed / особенность).
- Под карточками - 3 пустых слота Копья.
- Клик по карточке заполняет следующий свободный слот. Клик по заполненному слоту - освобождает его.
- Кнопка START GAME неактивна, пока не заполнены все 3 слота.
- Это же меню показывается между миссиями (см. раздел 7) - с сохранением прошлого состава как дефолта.

## 3. Копье бота (Enemy Lance) ✅

- Бот стартует с копьем из 3 случайных мехов (равновероятный выбор класса на слот).
- Мехи бота используют ту же DU-физику: `WEAPONS[wep].damage`, полная скорость пуль, щиты с regen +1/180f.
- Цвет щитов бота - красный (как сейчас у бота), игрока - cyan.
- Бот не респавнится. Если копье бота выбито полностью - на этой миссии врагов-мехов больше не будет. Все волны монстров и босс достаются копью игрока.

### 3.1 Rival Budget - рост угрозы соперника ✅

Персистентная прокачка вражеского копья через тот же магазин, что у игрока:

- У соперника виртуальный CE-кошелек: `RIVAL.budget += RIVAL.gainPerWin` ТОЛЬКО когда игрок выиграл контракт. При проигрыше игрока бюджет соперника не растет - death spiral исключен конструктивно.
- Перед каждой миссией AI "закупается" для своих 3 случайных мехов из ТОГО ЖЕ каталога `TACTICAL_UPGRADES` (те же цены, те же эффекты), пока бюджет не потрачен или не достигнут кап апгрейдов на меха (кап = как у игрока). Остаток бюджета переносится.
- Закупка взвешена по классу меха (heavy -> Bastion Shield и т.д.) - использовать метаданные каталога, никаких отдельных "вражеских" способностей не писать.
- Балансировка: `RIVAL.gainPerWin` ~ 30-50% от среднего CE босса, чтобы игрок на победах всегда опережал соперника. Число - в `balance.js`, секция `RIVAL`.
- Видимость: лоадаут вражеского копья показывать на экране старта миссии (contract briefing) - игрок знает те же апгрейды и мгновенно читает угрозу.
- Опциональный флавор: у копья соперника имя наемничьей компании + счетчик убитых им мехов игрока.

## 4. Спавн и формация ✅

- Оба копья стартуют НЕ в центре, а в случайных углах карты 3000x3000 (разные углы, не смежные клетки).
- Стартовая формация - треугольник: управляемый мех (или лидер бота) на острие, два ведомых сзади по флангам.
- FOLLOW-логика ведомых: держать позицию в треугольнике относительно лидера с допуском; при контакте с врагом - вести огонь, но не разбегаться дальше радиуса формации (радиус - в `balance.js`, новая секция `LANCE`).

## 5. Смерть и воскрешение ✅

- Мехи игрока и бота НЕ респавнятся сами. Смерть меха - до конца миссии (или до воскрешения).
- **"+1 союзник" УБРАТЬ из перков за уровень полностью.** Воскрешение переезжает в пул БОНУСОВ, падающих с врагов (как quad, freeze):
  - Новый бонус **Resurrect**: литера - выбрать свободную, не занятую существующими бонусами (кандидат: R; сверить с текущей картой литер бонусов и взять незанятую).
  - Подобрал - воскрешает 1 случайного мертвого меха СВОЕГО копья. Работает для обеих сторон: мех бота подобрал - воскресает мех бота.
  - Подобрал при полном копье (все 3 живы) - ничего не происходит, но бонус исчезает: denial-подбор, чтобы не достался врагу.
- Смерть всех 3 мехов игрока = провал миссии.

## 6. Цель миссии: контракт на босса ✅

- Миссия - соревнование двух копий за убийство босса (выполнение контракта).
- Копье бота активно охотится на босса, а не только на игрока: AI-приоритеты лидера бота - босс > мехи игрока > монстры (уточнить веса при балансировке).
- Босс убит игроком -> победа, переход на следующую карту через меню состава (раздел 2) + магазин (раздел 7).
- **Босс убит ботом**: НЕ геймовер. Миссия завершается, но игрок получает только 50% набранного за миссию CE и 0 CE за босса. Босс жирный - именно с него падает основной CE на апгрейды, так что проигрыш гонки бьет по кошельку, а не по прогрессу.
- **Боссы контракта - текущие три** (mantis / fortress / eye из оригинала, по биому карты). Их редизайн отложен: сначала доделывается геймплей на текущей графике, переработка боссов пойдет вместе с графической переделкой по Art Bible / Pixel Forge. В этой задаче боссов не трогать, только встроить в гонку контракта.

## 7. Combat Experience (замена Score) ✅

- Убрать SCORE из UI и из кода подсчета - он дублирует экспу.
- Единый параметр: **Combat Experience (CE)**.
- Внутри миссии: CE набирается в бою и служит основой левелинга меха и внутримиссионной прокачки (текущая система уровней остается, но питается от CE).
- Уровень меха обнуляется между миссиями: в начале каждой миссии любой мех - 1 lvl.
- Между миссиями: CE - валюта Магазина Тактических Апгрейдов.
- **Формула наград - расширение DU в экономику: 1 DU = 1 HP = 1 Shield = 1 Damage = 1 CE.**
  - Убийство вражеского меха: CE = `maxHP меха x его уровень`. Пример: мех 12 HP уровня 10 = 120 CE. (Щит в формулу НЕ входит - считается только HP; зафиксировать это явно в balance.js комментарием.)
  - Симметрично: бот получает CE за убитый мех игрока по той же формуле, и этот CE питает внутримиссионный левелинг мехов бота. Потерял меха - соперник прокачался.
  - Босс: CE = полный maxHP босса (босс 1000 HP = 1000 CE). Основной источник CE на тактические апгрейды.
  - Монстры: CE = их maxHP x hpMult (существующая экспа приводится к этой же формуле).
- CE как уровень/бафф из прошлой миссии не переносится никак.
- **Непотраченный CE не сгорает**: кошелек персистентен между миссиями. Помимо тактических апгрейдов, CE можно тратить на **косметический метагейм** (см. раздел 8.1).

## 8. Магазин Тактических Апгрейдов ✅

- Показывается после победной миссии, вместе с меню состава копья.
- Покупки - за CE.
- Апгрейды покупаются на конкретный мех выбранной тройки (слот+тип) и действуют на все следующие миссии.
- Если в слоте сменен ТИП меха - апгрейды этого слота обнуляются (без возврата CE). Пример: качал 2 heavy + 1 scout, заменил heavy на scout - новый scout голый, покупай заново.
- Тактические апгрейды меняют МЕХАНИКИ поведения, не только статы.
- **Streak-цены**: серия выигранных контрактов - скидка на апгрейды; серия проигранных - наценка. Поражение сбрасывает win streak, победа сбрасывает loss streak. Проценты и шаги - в `balance.js` (секция `STREAK`), показывать текущий модификатор в UI магазина.
