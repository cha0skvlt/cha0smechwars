# CHA0S MECH WARS

**Версия:** 7.3 STABLE  
**Платформа:** Браузер (HTML5 Canvas + Web Audio API)  
**Архитектура:** Single-file HTML, Vanilla JavaScript (без зависимостей)

## 🎮 Описание

CHA0S MECH WARS — это пиксельная top-down шутер-игра с элементами roguelike. Игрок управляет мехом в изометрическом мире, сражается с волнами врагов, собирает оружие и модули, развивает персонажа.

## ✨ Особенности

- **3 класса мехов:** Battle (баланс), Heavy (танк), Scout (быстрый)
- **5 типов оружия:** Pistol, Shotgun, MG, RPG, Laser с системой уровней
- **Система модулей:** Turret, Warp, EMP, Gravity Well, Overclock
- **Динамические биомы:** Forest, Ruins, Dungeon с уникальными врагами
- **Боссы:** Mantis, Fortress, Eye — каждые 10 волн
- **ИИ-соперник:** Бот-игрок с продвинутым ИИ
- **Система комбо:** Бонусы за убийства подряд
- **Процедурная генерация:** Карты и спавн врагов

## 🎯 Управление

- **WASD** — движение
- **Мышь** — стрельба
- **SPACE** — способность класса (Jetpack/Ram Dash/Turbo Jets)
- **SHIFT** — активация модуля
- **P** — пауза
- **S/M/R/L** — переключение оружия (Shotgun/MG/RPG/Laser)

## 🚀 Быстрый старт

1. Откройте `index.html` в современном браузере
2. Нажмите "INITIATE SYSTEM"
3. Выберите класс меха
4. Играйте!

**Требования:**
- Современный браузер с поддержкой HTML5 Canvas и Web Audio API
- Рекомендуется Chrome/Edge/Firefox последних версий

- **Рендеринг:** Canvas 2D с pixel-perfect режимом
