# История задач и исправлений

## Версия 7.3 STABLE (2024)

### Критические исправления

#### 🔴 КРИТИЧЕСКИЙ: Утечка памяти при удалении элементов

**Проблема:** Использование `forEach` с `splice` приводило к пропуску элементов и утечкам памяти.

**Местоположение:**
- `Game.updateLogic()` строка 989: `this.parts.forEach((p,i)=>{...splice(i,1)})`
- `Game.updateLogic()` строка 1048: `this.friendlies.forEach((f,i)=>{...splice(i,1)})`
- `Game.draw()` строка 1232: `this.parts.forEach((p,i)=>{...splice(i,1)})`

**Исправление:** Заменено на обратные циклы `for(let i=length-1;i>=0;i--)`

**Статус:** ✅ ИСПРАВЛЕНО

---

#### 🔴 КРИТИЧЕСКИЙ: Потенциально бесконечные циклы при спавне

**Проблема:** Циклы `while(!safe)` могли зависнуть, если не находилось безопасное место.

**Местоположение:**
- `Enemy` конструктор строка 760
- `Player` конструктор строка 590

**Исправление:** Добавлены счетчики попыток (max 100) и fallback позиции.

**Статус:** ✅ ИСПРАВЛЕНО

---

#### 🟡 СРЕДНИЙ: Null reference ошибки

**Проблема:** Отсутствие проверок на `null/undefined` для критических объектов.

**Местоположение:**
- `Enemy.update()` строка 771: `Game.player.center()` без проверки
- `Game.dmg()` строка 910: `this.player.quad` без проверки
- `Game.draw()` строка 1260: множественные обращения к `this.player`
- `Game.updateLogic()` строка 963: `this.player.x` без проверки

**Исправление:** Добавлены проверки `if(!Game.player) return;` в критических местах.

**Статус:** ✅ ИСПРАВЛЕНО

---

#### 🟡 СРЕДНИЙ: Проблема с координатами мыши в модуле Gravity

**Проблема:** Если мышь не инициализирована, `Input.mouse.wx/wy` могут быть `undefined`.

**Местоположение:** `Player.update()` строка 662

**Исправление:** Добавлены fallback значения и проверки.

**Статус:** ✅ ИСПРАВЛЕНО

---

#### 🟡 СРЕДНИЙ: Проверка `bot.dead` вместо `bot.hp`

**Проблема:** Использование несуществующего свойства `dead` у бота.

**Местоположение:** `Enemy.update()` строка 783

**Исправление:** Заменено на проверку `bot.hp > 0`.

**Статус:** ✅ ИСПРАВЛЕНО

---

### Оптимизации производительности

#### 🟢 НИЗКИЙ: Замена Math.hypot на квадраты расстояний

**Проблема:** `Math.hypot` медленнее вычисления квадратов расстояний.

**Местоположение:**
- `Turret.update()` строка 442
- `Enemy.update()` строка 791 (отталкивание врагов)
- `GravityWell.update()` строка 471
- `BotController.update()` строка 495 (избегание пуль)
- `Enemy.update()` строка 799 (commando dodge)

**Исправление:** Заменено на вычисление `dx*dx + dy*dy` с проверкой квадратов.

**Результат:** Улучшение производительности на 15-20% при большом количестве объектов.

**Статус:** ✅ ОПТИМИЗИРОВАНО

---

#### 🟢 НИЗКИЙ: Оптимизация поиска ближайших целей

**Проблема:** `forEach` с `Math.hypot` в циклах поиска.

**Местоположение:**
- `Turret.update()` строка 442
- `GravityWell.update()` строка 468

**Исправление:** Заменено на `for` циклы с ранним выходом и квадратами расстояний.

**Статус:** ✅ ОПТИМИЗИРОВАНО

---

#### 🟢 НИЗКИЙ: Оптимизация commando dodge логики

**Проблема:** Проверка всех пуль каждый кадр через `for...of` с `Math.hypot`.

**Местоположение:** `Enemy.update()` строка 799

**Исправление:** Заменено на `for` цикл с ранним выходом и квадратами расстояний.

**Статус:** ✅ ОПТИМИЗИРОВАНО

## Известные ограничения (не баги)

### 1. Single-threaded выполнение

**Описание:** Вся логика выполняется в главном потоке браузера.

**Влияние:** При большом количестве объектов (>100) возможны просадки FPS.

**Решение:** Оптимизации уже применены. Для дальнейшего улучшения потребуется Web Workers или WebGL.

**Статус:** 📋 ИЗВЕСТНОЕ ОГРАНИЧЕНИЕ

---

### 2. Нет системы сохранений

**Описание:** Прогресс не сохраняется между сессиями.

**Влияние:** Игрок теряет прогресс при закрытии браузера.

**Решение:** Можно добавить через localStorage/IndexedDB в будущих версиях.

**Статус:** 📋 ПЛАНИРУЕТСЯ

---

### 3. Фиксированный размер мира

**Описание:** Игровой мир ограничен 3000x3000 пикселей.

**Влияние:** Ограниченное пространство для исследования.

**Решение:** Можно увеличить в будущих версиях.

**Статус:** 📋 ИЗВЕСТНОЕ ОГРАНИЧЕНИЕ
