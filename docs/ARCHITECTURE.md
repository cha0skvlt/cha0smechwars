# Архитектура CHA0S MECH WARS

## Обзор

CHA0S MECH WARS построена как single-file HTML приложение на чистом JavaScript без внешних зависимостей. Игра использует Canvas 2D для рендеринга и Web Audio API для звука.

## Структура кода

### Основные модули

```
index.html
├── HTML структура (меню, UI)
├── CSS стили (встроенные)
└── JavaScript (встроенный)
    ├── DOM утилиты
    ├── Sprites система
    ├── AudioSys (Web Audio API)
    ├── Canvas/рендеринг
    ├── Grid (пространственная сетка)
    ├── Entity система
    │   ├── Player
    │   ├── Enemy
    │   ├── Bullet
    │   ├── Obstacle
    │   ├── Particle
    │   ├── Turret
    │   └── GravityWell
    ├── BotController (ИИ)
    └── Game (главный цикл)
```

## Системы

### 1. Рендеринг

**Canvas:** Один canvas элемент для всей игры  
**Pixel-perfect:** `image-rendering: pixelated` для ретро-стиля  
**Interpolation:** Lerp для плавной анимации между кадрами  
**Layers:** Фон → Объекты → Игроки → Пули → Эффекты → UI

**Оптимизации:**
- Frustum culling (отсечение невидимых объектов)
- Кэширование спрайтов в Canvas элементах
- Batch rendering где возможно

### 2. Физика и коллизии

**Grid система:** Пространственная сетка 128x128 для быстрого поиска коллизий  
**AABB:** Axis-Aligned Bounding Box для всех объектов  
**Реакция на коллизии:** Push-out алгоритм для разрешения застреваний

**Класс Entity:**
```javascript
class Entity {
    x, y, w, h          // Позиция и размер
    lastX, lastY       // Для интерполяции
    center()           // Центр объекта
    rectIntersect()    // Проверка пересечения
}
```

### 3. Игровая логика

**Fixed timestep:** 60 FPS логика с интерполяцией для плавности  
**Game loop:** `requestAnimationFrame` с аккумулятором времени

**Основные массивы:**
- `enemies[]` — враги
- `bullets[]` — пули
- `pows[]` — пауэр-апы
- `parts[]` — частицы
- `friendlies[]` — турели и гравитационные колодцы
- `obs[]` — препятствия

### 4. Система классов

**Battle (базовый):**
- HP: 10, Shield: 5, Speed: 4.5
- Jetpack способность
- Баланс между защитой и мобильностью

**Heavy:**
- HP: 15, Shield: 10, Speed: 3.5
- Ram Dash способность (урон + отталкивание)
- Не может летать

**Scout:**
- HP: 8, Shield: 3, Speed: 5.0
- Turbo Jets (3x топливо, 2x скорость полета)
- Хрупкий, но быстрый

### 5. Система оружия

**Типы:**
- `pistol` — базовое, быстрый огонь
- `shotgun` — близкий бой, разброс
- `mg` — автоматическое, средний урон
- `rpg` — взрывное, медленное
- `laser` — дальний бой, пробивает

**Уровни:** Каждое оружие имеет уровни (1-3+), улучшающие характеристики

**Модификаторы:**
- Quad Damage (x4 урон)
- Overclock (x0.5 перезарядка)

### 6. Система модулей

**Turret:** Стационарная турель, стреляет по врагам  
**Warp:** Замедляет время (timeScale = 0.2)  
**EMP:** Урон всем врагам + очистка пуль + стан  
**Gravity Well:** Притягивает врагов к точке  
**Overclock:** Ускоряет перезарядку, блокирует реген щита

**Cooldown:** Каждый модуль имеет индивидуальный кулдаун

### 7. ИИ врагов

**Типы врагов:**
- `zombie` — базовый, медленный
- `gunner` — стрелок на дистанции
- `rocketman` — ракетчик
- `tank` — тяжелый, стреляет дробовиком
- `commando` — уклоняется от пуль
- `stalker` — быстрый, зигзагообразное движение
- `sniper` — дальний бой, лазер
- `mantis` — босс, фазы атаки
- `fortress` — босс, турель
- `eye` — босс, орбитальное движение

**Поведение:**
- State machine для каждого типа
- Pathfinding через избегание препятствий
- Динамический выбор цели (игрок/турели/бот)

### 8. BotController (ИИ-соперник)

**Стратегия:**
- Избегание пуль (векторное поле)
- Приоритизация лута (модули > ремонт > оружие)
- Динамическое позиционирование (зависит от оружия)
- Использование модулей в критических ситуациях

**Приоритеты:**
1. Выживание (избегание пуль)
2. Сбор модулей и ремонта
3. Атака врагов
4. Атака игрока (если возможно)

### 9. Аудио система

**Web Audio API:**
- Процедурная генерация звуков (осцилляторы)
- Позиционный звук (stereo panning)
- Динамические фильтры (lowpass при низком HP)
- Музыка (процедурная, зависит от состояния)

**Звуки:**
- Выстрелы (разные для каждого оружия)
- Взрывы
- Удары
- Модули
- Музыка (game/boss треки)

### 10. Система биомов

**Forest:**
- Деревья и дома
- Зеленая палитра
- Босс: Mantis

**Ruins:**
- Каменные стены
- Серая палитра
- Босс: Fortress

**Dungeon:**
- Пещерные стены
- Темная палитра
- Босс: Eye

**Переключение:** Каждые 10 волн (после босса)

## Производительность

### Оптимизации

1. **Пространственная сетка:** O(1) поиск коллизий вместо O(n²)
2. **Frustum culling:** Рендеринг только видимых объектов
3. **Квадраты расстояний:** Избегание `Math.hypot` где возможно
4. **Обратный цикл:** Удаление элементов через `for(i=length-1;i>=0;i--)`
5. **Кэширование:** Спрайты предварительно рендерятся в Canvas

### Профилирование

**Критические пути:**
- Обновление врагов (O(n))
- Коллизии пуль (O(n*m))
- Рендеринг (O(n))

**Узкие места:**
- `Math.hypot` заменен на квадраты расстояний
- `forEach` с `splice` заменен на обратные циклы
- Оптимизирован поиск ближайших целей

## Безопасность и надежность

### Обработка ошибок

- Проверки на `null/undefined` для критических объектов
- Try-catch в игровом цикле
- Ограничения на бесконечные циклы (спавн врагов)
- Валидация входных данных

### Граничные случаи

- Игрок мертв → безопасный режим рендеринга
- Бот отсутствует → проверки перед использованием
- Пустые массивы → безопасная итерация
- Деление на ноль → проверки перед вычислениями

## Расширяемость

### Добавление нового врага

1. Добавить спрайт в `Sprites`
2. Добавить логику в конструктор `Enemy`
3. Добавить AI в `Enemy.update()`
4. Добавить в пул спавна

### Добавление нового модуля

1. Добавить в `applyPowerup()`
2. Добавить логику активации в `Player.update()`
3. Добавить в UI обновление
4. Добавить в лут-таблицу

### Добавление нового оружия

1. Добавить в `Player.update()` логику стрельбы
2. Добавить звук в `AudioSys.shoot()`
3. Добавить в UI отображение
4. Добавить в лут-таблицу

## Известные ограничения

1. **Single-threaded:** Вся логика в главном потоке
2. **Нет сохранений:** Прогресс не сохраняется
3. **Фиксированный размер:** 3000x3000 игровой мир
4. **Нет сетевой игры:** Только локальная игра
