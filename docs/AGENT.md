# Документация для ИИ-агентов

## Назначение

Этот документ предназначен для ИИ-агентов (LLM, автономные системы), которые работают с кодом CHA0S MECH WARS. Содержит структурированную информацию о кодовой базе, архитектуре и правилах модификации.

## Ключевые принципы

### 1. Single-file архитектура

**ВАЖНО:** Игра должна оставаться в одном файле `index.html`. Не разделять на модули, не использовать npm/package.json.

**Причины:**
- Простота распространения
- Нет зависимостей
- Легко открыть и играть

### 2. Vanilla JavaScript

**Запрещено:**
- npm пакеты
- Сборщики (webpack, rollup, etc.)
- Фреймворки (React, Vue, etc.)
- Библиотеки (jQuery, lodash, etc.)

**Разрешено:**
- Нативный JavaScript (ES5+)
- Web APIs (Canvas, Audio, etc.)
- Встроенные функции браузера

### 3. Совместимость

**Целевые браузеры:**
- Chrome/Edge 90+
- Firefox 88+
- Safari 14+

**Не использовать:**
- Экспериментальные API
- Полифиллы
- Транспиляцию

## Архитектура кода

### Основные классы

```javascript
// Базовый класс для всех игровых объектов
class Entity {
    constructor(x, y, w, h)
    center()              // Возвращает центр объекта
    rectIntersect(r)      // Проверка пересечения прямоугольников
    saveState()           // Сохраняет позицию для интерполяции
}

// Игрок
class Player extends Entity {
    constructor(type, isBot)
    update()              // Обновление логики
    draw(alpha)           // Рендеринг
    takeDamage(amt, source)
}

// Враг
class Enemy extends Entity {
    constructor(type)
    update()              // AI логика
    draw(alpha)
}

// Пуля
class Bullet extends Entity {
    constructor(x, y, ang, wep, enemy, lvl)
    update()
    draw(alpha)
}
```

### Глобальные объекты

```javascript
Game = {
    player: Player,           // Игрок
    bot: Player,              // ИИ-соперник
    enemies: Enemy[],         // Враги
    bullets: Bullet[],        // Пули
    pows: Powerup[],          // Пауэр-апы
    friendlies: Entity[],     // Турели, гравитационные колодцы
    obs: Obstacle[],          // Препятствия
    parts: Particle[],        // Частицы
    // ... другие массивы
}
```

### Игровой цикл

```javascript
Game.loop(currentTime) {
    // Fixed timestep с интерполяцией
```

## Правила модификации

### ✅ Можно делать

1. **Исправление багов**
   - Утечки памяти
   - Логические ошибки
   - Ошибки производительности

2. **Оптимизация**
   - Улучшение алгоритмов
   - Кэширование вычислений
   - Оптимизация циклов

3. **Улучшение надежности**
   - Проверки на null/undefined
   - Обработка граничных случаев
   - Защита от ошибок

4. **Рефакторинг**
   - Улучшение читаемости
   - Устранение дублирования
   - Улучшение именования

### ❌ Нельзя делать

1. **Разделение на файлы**
   - Не создавать отдельные .js файлы
   - Не использовать модули
   - Не использовать import/export

2. **Добавление зависимостей**
   - Не добавлять npm пакеты
   - Не использовать CDN библиотеки
   - Не добавлять внешние ресурсы (кроме шрифтов)

3. **Изменение архитектуры**
   - Не менять основную структуру классов
   - Не переписывать игровой цикл полностью
   - Не менять систему рендеринга кардинально

4. **Удаление функционала**
   - Не удалять существующие механики
   - Не упрощать систему без необходимости
   - Не удалять классы/типы врагов

## Критические участки кода

### 1. Удаление элементов из массивов

**❌ НЕПРАВИЛЬНО:**
```javascript
array.forEach((item, i) => {
    if(condition) array.splice(i, 1);  // БАГ!
});
```

**✅ ПРАВИЛЬНО:**
```javascript
for(let i = array.length - 1; i >= 0; i--) {
    if(condition) array.splice(i, 1);
}
```

### 2. Вычисление расстояний

**❌ МЕДЛЕННО:**
```javascript
let dist = Math.hypot(x1 - x2, y1 - y2);
if(dist < radius) { ... }
```

**✅ БЫСТРО:**
```javascript
let dx = x1 - x2, dy = y1 - y2;
let distSq = dx*dx + dy*dy;
if(distSq < radius*radius) {
    let dist = Math.sqrt(distSq);
    // ...
}
```

### 3. Проверки на null

**❌ ОПАСНО:**
```javascript
Game.player.x  // Может быть null
```

**✅ БЕЗОПАСНО:**
```javascript
if(Game.player) {
    Game.player.x
}
```

## Тестирование изменений

### Чек-лист перед коммитом

- [ ] Игра запускается без ошибок
- [ ] Все классы мехов работают
- [ ] Все типы врагов спавнятся
- [ ] Оружие стреляет корректно
- [ ] Модули активируются
- [ ] Бот работает
- [ ] Нет утечек памяти (проверить через DevTools)
- [ ] Производительность не ухудшилась

### Типичные проблемы

1. **Бесконечные циклы:** Всегда добавлять счетчики попыток
2. **Утечки памяти:** Удалять элементы из массивов правильно
3. **Null reference:** Проверять объекты перед использованием
4. **Производительность:** Избегать Math.hypot в циклах

## Частые задачи

### Добавление нового врага

1. Добавить спрайт в `Sprites` объект
2. Добавить логику в `Enemy` конструктор
3. Добавить AI в `Enemy.update()`
4. Добавить в пул спавна в `Game.updateLogic()`

### Исправление бага с производительностью

1. Найти медленный участок (DevTools Profiler)
2. Заменить `Math.hypot` на квадраты расстояний
3. Оптимизировать циклы (избегать forEach с splice)
4. Добавить ранний выход из циклов

### Добавление проверки на null

1. Найти использование объекта
2. Добавить проверку `if(!obj) return;`
3. Проверить все места использования
4. Протестировать граничные случаи
